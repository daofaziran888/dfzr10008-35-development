# 数据产品与API工厂

面向数据产品经理与开发者的数据产品快速构建平台。覆盖数据产品定义、API接口生成、数据模型封装、产品版本管理、调用配额控制、文档自动生成、产品市场分发与使用效果追踪的完整数据产品链路。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 数据产品认证：按产品归属管控

认证记录绑定已登记的数据产品，并按产品归属控制申请与审核：

- **申请权限**：只有产品负责人（同属产品归属单位）能提交认证；非归属单位进入只读态（接口返回 `只读/readonly` 与 `permissions`），
  跨单位提交被拒绝且不落记录。
- **申请冻结**：提交时冻结 `认证标准`、`有效期限`、`有效期起/至`、`标准符合性结果`（`冻结字段` 可查），
  审核动作里改写这些字段会被拒绝；`延期认证` 是唯一调整有效期的入口。
- **共享材料**：`标准核对表 STD-07`、`负责人签字`、`有效期区间` 在申请时一并冻结，`GET /api/badge/{id}/materials` 可查，
  任何修改请求一律拒绝。
- **唯一审核结果**：同一产品 + 同一认证标准只保留一条认证审核结果，重复提交返回已有记录编号而不新增。
- **审核归属**：审核只允许归属单位操作，跨单位审核被拒绝，原状态与审核结论保留不变。
- **发布准入回写**：审核通过时 `标准符合性结果=通过` 并写入产品发布准入（`GET /api/product/admission?product_no=...`）；
  驳回或有效期满则立即移出可用认证集合（`GET /api/badge/available`），准入同时读不到该认证。
- **操作人身份**：可用查询参数 `operator`/`unit` 或请求头 `X-Operator`/`X-Operator-Unit` 传入，姓名按平台账号目录映射归属单位。

示例数据：`BADGE-0003` 属于 `PROD-0007`，标准「数据口径可追溯 v1」，有效期至 2027-06-30，负责人与申请人为周宁（华东渠道组）；
华南渠道组的陈然提交或审核该产品都会被拒绝。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。
